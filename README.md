# Profilia

AI-powered resume to portfolio converter that transforms your professional documents into stunning, personalized web portfolios.

## 🌐 Live App

**Website:** [https://profilia.solutionsynth.cloud](https://profilia.solutionsynth.cloud)

## ✨ What is Profilia?

Profilia is a web application that automatically converts your resume (PDF or Word) into a beautiful, responsive HTML portfolio. Simply upload your resume, choose a username, and get a permanent personalized URL to showcase your professional profile.

## 🎯 Key Features

- **Easy Upload**: Drag and drop or select your resume file (PDF, DOC, DOCX)
- **AI Generation**: Advanced AI analyzes your resume and creates a stunning portfolio with modern design
- **Permanent URLs**: Get your own custom URL like `profilia.solutionsynth.cloud/portfolio/yourname`
- **Real-time Progress**: Watch your portfolio being created with live progress updates
- **Username Availability**: Check if your desired username is available before uploading
- **Portfolio Search**: Find and view portfolios by username
- **Instant Results**: Portfolio generated and hosted in under 2 minutes

## 🎨 Design

Portfolios feature a modern cyberpunk-inspired design with:
- Gradient backgrounds and smooth animations
- Professional layout optimized for recruiters
- Responsive design that works on all devices
- Eye-catching color scheme (cyan, purple, orange accents)

## 💰 Cost Efficiency

Profilia is designed to be highly cost-effective:
- **Per Portfolio**: ~$0.50 (mainly AI generation costs)
- **No Fixed Costs**: Pay only for what you use
- **Scalable**: Handles 1 or 1,000 portfolios efficiently

## 🚀 How It Works

1. **Upload**: Choose your resume file and pick a username
2. **Process**: AI extracts information and generates a custom portfolio
3. **Deploy**: Portfolio is automatically published to your permanent URL
4. **Share**: Use your personal portfolio link for job applications and networking

## 🛠️ Technology

Built with modern cloud infrastructure for reliability and performance:
- AI-powered content generation using Claude Sonnet 4.5
- Serverless architecture for automatic scaling
- Global content delivery for fast loading worldwide
- Secure file processing and storage
